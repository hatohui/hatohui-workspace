# Travel features

A food catalog and trip planner: dishes, the places that serve them well, events, shared travel plans, activity timelines, and personal leave tracking.

| Feature                  | Sub-features                                                                                                                                                                                                                                                                                                                                                                                           | Spec                                                         |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| Food catalog             | • Photo and name cards<br>• Detail panel with embedded map<br>• Search with suggestions<br>• Filter sidebar on desktop<br>• Filter sheet on mobile<br>• Spicy filter<br>• Diet filters<br>• Cuisine filters<br>• Avoid allergens<br>• Filter by @handle<br>• Compact prices<br>• Creator credit                                                                                                        | [spec](../../docs/specs/travel/food-catalog/README.md)       |
| Food editor              | • Add a dish at a place<br>• Create dish or place inline<br>• Multiple photos<br>• Drag-and-drop photos<br>• Cover photo<br>• Price range or level<br>• Price presets<br>• Spicy tag<br>• Diet tags with icons<br>• Allergen tags<br>• Cuisine tags<br>• Edit and delete                                                                                                                               | [spec](../../docs/specs/travel/food-catalog/README.md)       |
| Dishes                   | • Dish list<br>• Dish photo<br>• Tag, cuisine, allergen and @handle filters<br>• Search with suggestions<br>• Where to eat it<br>• Edit and delete a dish                                                                                                                                                                                                                                              | [spec](../../docs/specs/travel/food-catalog/README.md)       |
| Places                   | • Place list<br>• What to order there<br>• Embedded map<br>• Google Maps link<br>• Short share links<br>• Coordinates from Maps link<br>• Map preview while editing<br>• Edit and delete a place                                                                                                                                                                                                       | [spec](../../docs/specs/travel/food-catalog/README.md)       |
| Locations                | • Country and area picker<br>• Remembered per browser<br>• New places filed under the picked area                                                                                                                                                                                                                                                                                                      | [spec](../../docs/specs/travel/admin/README.md)              |
| Admin                    | • Editor access from a system parameter<br>• Quick recommendations add and edit<br>• Inline-edit tables with search and optimistic updates<br>• Quick add many at once<br>• One-click delete<br>• Countries and areas<br>• Dishes and cuisines<br>• Diet and allergen tags<br>• Pending public event approval & hard-delete<br>• Searchable travel groups overview & stats<br>• Job-profile management | [spec](../../docs/specs/travel/admin/README.md)              |
| Account                  | • Google sign-in<br>• Theme                                                                                                                                                                                                                                                                                                                                                                            |                                                              |
| Photo variants           | • 512px WebP thumbnails and 2048px WebP previews for dish, recommendation, event, group and activity photos<br>• Queue retry on failure                                                                                                                                                                                                                                                                | [spec](../../docs/specs/art/storage-layout/README.md)        |
| Travel dashboard         | • Side-by-side overview with leave balance, upcoming plans and quick actions                                                                                                                                                                                                                                                                                                                           | [spec](../../docs/specs/travel/leave-and-schedule/README.md) |
| Events                   | • Public and private conventions/furmeets<br>• Public event approval queue<br>• Yearly recurring flag<br>• Timeline, calendar and list views<br>• Search and location filtering<br>• Event detail dialog<br>• Event cover photo with WebP variants<br>• Location link and optional catalog area/place link                                                                                             | [spec](../../docs/specs/travel/events/README.md)             |
| Travel plans & groups    | • Event-linked or standalone participations<br>• Travel window, leave type, flight numbers and already-here flag<br>• Overlap prevention<br>• Named travel groups with owner<br>• Member invites and join requests<br>• Kick, leave with auto-promotion, and ownership transfer<br>• Granular public visibility                                                                                        | [spec](../../docs/specs/travel/plans/README.md)              |
| Activity timeline        | • Per-group itinerary with time window, location, notes and cover photo<br>• Optional food-catalog place link<br>• Include/exclude participant tagging<br>• Auto-generated arrival/departure cards (same-time merged)<br>• Event boundary toggle<br>• Search, member filter, sort and upcoming widget                                                                                                  | [spec](../../docs/specs/travel/plans/README.md)              |
| Plan media gallery       | • Group-level and per-activity photo galleries<br>• WebP thumbnails and previews<br>• Filter by activity or uploader<br>• Lightbox viewer                                                                                                                                                                                                                                                              | [spec](../../docs/specs/travel/plans/README.md)              |

| Travel notifications     | • In-app notifications bell for invites, join requests, approvals/rejections, kicks, leaves, ownership transfers and deletions<br>• Unread badge and mark-all-read                                                                                                                                                                                                                                     | [spec](../../docs/specs/travel/plans/README.md)              |
| Leave balance            | • Personal job profile (annual leave, sick leave, rolling cycle start)<br>• Used/remaining breakdown per cycle<br>• Cycle allowance confirmation<br>• Working-day leave calculation                                                                                                                                                                                                                    | [spec](../../docs/specs/travel/leave-and-schedule/README.md) |
| Work schedule & holidays | • Configurable weekly work days<br>• Per-date schedule exceptions (forced work/off)<br>• Country public holidays (`date-holidays`, cached)<br>• Custom personal holidays<br>• Monthly schedule calendar<br>• Fractional-day leave heatmap                                                                                                                                                              | [spec](../../docs/specs/travel/leave-and-schedule/README.md) |
